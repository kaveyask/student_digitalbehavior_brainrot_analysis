🛒 Blinkit Quick-Commerce Analytics | Power BI
An interactive Power BI analytics project analyzing Blinkit's quick-commerce operations across Orders, Customers, Delivery, Inventory, Marketing, and Customer Feedback.

📊 Project Overview
103K+ records across 8 interconnected tables
5,000+ orders | 2,500 customers | 268 products
Data period: March 2023 – November 2024
🛠️ Tools & Skills
Power BI | Power Query | DAX | Excel | Data Modeling | Data Visualization

🔧 Key Work Performed
Data Cleaning & Transformation – handled missing values, duplicates, inconsistent values and data types using Power Query.
Data Modeling – connected 8 tables and established relationships for cross-functional analysis.
DAX Development – created measures for revenue, orders, customers, quantity, delivery success rate, repeat customers, damage %, ROAS and other KPIs.
KPI Development – designed business-focused KPI cards to monitor overall performance.
Interactive Dashboarding – built 4 analytical pages with slicers, cross-filtering, page navigation and interactive tooltips.
Business Analysis – analyzed customer behavior, delivery performance, inventory damage, product performance and marketing efficiency.
Data Visualization – used appropriate charts and visual elements to present trends and comparisons clearly.

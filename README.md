# 🧠 Student Digital Behavior & Brain Rot Analysis | MySQL

A SQL-driven **data analytics project** analyzing global student digital behavior across **social media, online learning, short-form videos, entertainment, academic performance, wellbeing, and digital addiction**.

### 📊 Project Overview

- **500,000** student records across global countries and development levels
- **47 attributes** covering demographics, digital behavior, academics, wellbeing and risk indicators
- Analysis structured around **15 analytical questions**
- Data cleaning, transformation and analysis performed entirely using **MySQL**

### 🛠️ Tools & Skills

**MySQL | SQL | Data Cleaning | Data Analysis | CTEs | Window Functions | Dynamic SQL**

### 🔧 Key Work Performed

- **Data Loading** – imported 500K+ records into MySQL using `LOAD DATA INFILE`.
- **Data Cleaning** – checked duplicate records and performed a dynamic NULL/blank audit across all columns.
- **Data Transformation** – rebuilt missing `brain_rot_level` values using Brain Rot Index thresholds.
- **Feature Engineering** – created `digital_addiction_level` from digital addiction scores.
- **Exploratory Analysis** – analyzed demographics, digital usage, income levels and student behavior.
- **Advanced SQL Analysis** – used CTEs, subqueries, conditional aggregation and `CASE WHEN` logic.
- **Ranking Analysis** – used `DENSE_RANK()` to identify the top 3 countries by Brain Rot Index within each development level.
- **Relationship Analysis** – examined social media and short-form video usage in relation to Brain Rot levels.
- **Business Insights** – analyzed academic motivation, productivity, digital spending and risk exposure.
